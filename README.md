# SOCAction – Secure Authentication Monitoring System

SOCAction is a Java secure authentication and security monitoring application that is created using Spring Boot, Spring Security, BCrypt, MySQL and Thymeleaf frameworks.

The platform provides secure user authentication, together with SOC-type dashboard for monitoring of authentication activity, failed logins, active sessions, IP address activity, threats and security events.

---

## Cybersecurity Features

- Secure Authentication via Spring Security
- BCrypt Password Hashing for secure password storing
- User Authentication and Authorization
- Monitoring of Failed Logins
- Monitoring of Authentication Activity
- Monitoring of IP Addresses
- Monitoring of Active Sessions
- Monitoring of Threats
- Risk Classification
- Login Analytics
- SOC-type Security Dashboard
- Monitoring of Authentication Events
- Secure Logout
- Role-based Access Control

---

## Key Features

### 1. Secure Login

The users are authenticated via Spring Security login.

The platform verifies credentials and manages successful and unsuccessful authentication attempts.

### 2. Secure Password Storing

The passwords are hashed via BCrypt algorithm instead of storing plain text passwords.
